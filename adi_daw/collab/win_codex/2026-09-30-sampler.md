# Sampler — checklist written before code

Source: Live 12 Instrument Reference, Sampler, printed pp.744–762; own wording. Mission scope is OneShot voice reuse plus multisample zones, loops/crossfades and modulation.

- Key, velocity and sample-select ranges independently gate each zone; overlapping zones layer.
- Zone fades weight the attack; moving sample select does not replace a voice already sounding.
- Root key, tuning, level and pan belong to the zone.
- Each zone has sample start/end and sustain-loop boundaries, with a loop crossfade; release ends through the inherited envelope.
- Reuse OneShot's interpolation, amplitude envelope, filter and per-voice tempo/free LFO, and the native modulation event path. No separate duplicate sampler oscillator.
- Sample/configuration building and state serialization are message-thread work; publication is immutable, audio allocation-free.
- Test exact zone boundaries, select changes during held notes, overlapping layers, loop/crossfade continuity, modulation, state replay, all callback sizes 32–4096, and measured nonzero sample output.

Native `adi.sampler` is chosen because #206's reusable OneShot engine is native. This avoids moving PCM through Pd or duplicating the voice engine. Initial bounded implementation targets the mission's multisample core; full Live FM/AM, three-LFO matrix, disk streaming, proprietary imports and zone editor are not claimed.

## Result

Native `adi.sampler` resolves in Session without a plugin loader. Up to 32 zones share OneShot's proven interpolation/envelope/filter/LFO implementation; only root-key configuration is added to OneShot. Zones and PCM are prepared before SnapshotPublisher publication. Releases and expression reach voices regardless of subsequent select changes. Bank replacement resets that bank's voices; it is safe during rendering, not a seamless held-note migration.

MSVC /WX: Sampler 28 checks, OneShot regression 100 checks. Every integer block size 32–4096 is sample-identical. Allocation audit, concurrent bank publication, exact state replay, range/fade/layer checks and loop-wrap comparison pass. A real Session MIDI clip triggers the native device; far bin floor is checked before the tone, and output is written as float WAV in a test temp folder. No speakers.

This mission's per-zone loop uses OneShot's forward sustain loop ending at the zone end and constant-power wrap crossfade. Ping-pong, separate release loops, full Live FM/AM/modulation matrix and bespoke zone editor remain parity extensions; inherited ADSR, filter, tempo/free LFO and mapped ParamMod are present. Total PCM publication limit is 128 MiB, 32 zones with up to 32 voices each (ADI engineering limits).
