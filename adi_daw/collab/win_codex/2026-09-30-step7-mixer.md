# Step 7.6 — checklist before implementation

Live 12 Mixing, printed pp.389–393; ADR-0195 d3/d4. Own wording:
- Mixer strips follow the same track order as arrangement; volume, pan, track activator and solo edit the project with undo. Pan resets to centre.
- Peak/RMS meters read audio-thread scalar publication, never project ops or snapshots.
- Only the visible strip span plus a margin is realised. Scrolling must not retarget an active gesture.
- Auto Gain Stage is one explicit command, with gated RMS default and LUFS-I choice; it calls the existing deterministic offline engine and one transaction, never an output device.
- MIDI Learn is a visible mixer action for the selected control; guards Remote and the live Focus Dial reservation, resolves encoder mode before journalling, and exposes colliding bindings as shadowed. Unbind is undoable.
- Tests cover track order, edits/undo, meter publication, visible-span allocation, menu/button routing and Learn reservation/replay.

Scope: existing engine stereo pan law, not a new split-pan implementation; no aux sends (rejected ADR-0072). A direct target Learn helper is needed because a mixer control exists before it has an automation lane. It shares the lane helper's policy and binding construction instead of inventing a hidden lane or writing SQL in a component.
