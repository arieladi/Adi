# Step 7.6 — checklist before implementation

Live 12 Mixing, printed pp.389–393; ADR-0195 d3/d4. Own wording:
- Mixer strips follow the same track order as arrangement; volume, pan, track activator and solo edit the project with undo. Pan resets to centre.
- Peak/RMS meters read audio-thread scalar publication, never project ops or snapshots.
- Only the visible strip span plus a margin is realised. Scrolling must not retarget an active gesture.
- Auto Gain Stage is one explicit command, with gated RMS default and LUFS-I choice; it calls the existing deterministic offline engine and one transaction, never an output device.
- MIDI Learn is a visible mixer action for the selected control; guards Remote and the live Focus Dial reservation, resolves encoder mode before journalling, and exposes colliding bindings as shadowed. Unbind is undoable.
- Tests cover track order, edits/undo, meter publication, visible-span allocation, menu/button routing and Learn reservation/replay.

Scope: existing engine stereo pan law, not a new split-pan implementation; no aux sends (rejected ADR-0072). A direct target Learn helper is needed because a mixer control exists before it has an automation lane. It shares the lane helper's policy and binding construction instead of inventing a hidden lane or writing SQL in a component.

Implemented MixerPanel with a window-sized strip pool, borrowing the root frame snapshot in track order. Structural controls are allocated on resize, not a frame drain. Dragging freezes recycling; retiring a track disables its strip. Volume/pan commit on release, text/keyboard edits immediately; mute/solo and pan reset use ops. Peak/RMS are audio-thread scalar atomics on session-owned StripNodes; no FFT or ops in metering.

Auto Gain Stage invokes the existing isolated offline session, gated RMS or LUFS-I at -18, with one undo transaction. MIDI Learn has an explicit Remote-port chooser and observes three CC values before binding. The direct-target helper shares the existing policy/resolved-payload path with lane Learn. Unbind is undoable. The menu reports Focus Dial collisions as shadowed, and dispatch gives the reservation first refusal. Hardware Remote selection is session-local until the device settings UI lands; no ambient machine identity enters project ops. This slice does not implement the broader hover/last-plugin Focus Dial gesture routing. ADI mixer UI fader range is -90..+6 dB, not a new Live-parity claim.

Validation: native MSVC /WX application build; 115 UI checks including software reference renders, visible-span bound, active-gesture recycling guard, volume/pan/mute + undo, and zero allocations on stable and generation-change frame drains. 60 document checks include real clip meter publication, Learn guard, lane-free bind, shadow reporting, and exact Unbind undo. No audio device opened. Includes #204's Analyse-button font mask correction.
