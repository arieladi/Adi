# Delay — manual checklist before implementation

Mission 4, delegated by win. Live 12 §28.11, printed pp.566–569, read before code.

- [ ] Independent left/right delay in milliseconds (manual: 1–5000) or numbered
  sixteenth notes; independent signed offsets, including while Stereo Link is on.
- [ ] Stereo Link follows changes from either side; independent feedback loops,
  optional Ping Pong cross-feedback, Freeze recirculates and ignores new input.
- [ ] Switchable bandpass before delay, Freq and Width; LFO modulates both delay
  time and filter with seven waveforms and Morph.
- [ ] LFO Rate/Time/Synced/Triplet/Dotted/Sixteenth modes.
- [ ] Repitch (manual default), Fade and Jump respond differently to time edits.
- [ ] Hi-Quality interpolation/smoothing; linear or equal-loudness Dry/Wet.
- [ ] Impulse timing in ms and sync using io.transport, zero allocations,
  block equality 32–4096, real-Pd far-bin-first tone and clean console, file only.
- [ ] Human Live parity session; one table of all unverified values.

Source read: Surge `58914e59c608ed4384ba6002e44c3465c58b2e71`,
libs/sst/sst-effects/include/sst/effects/Delay.h. Adapt its stereo circular
read/feedback/crossfeed/write topology into a scalar sample kernel, retaining
upstream GPL notices. Live's time, freeze, transitions and LFO controls take
precedence over Surge's log time, clipping, unison/pan and modulation controls.

## Implementation choices

GPL-3-or-later scalar adaptation of Surge SST Delay's stereo ring-buffer,
feedback and crossfeed topology; upstream notice retained. Live controls take
precedence: numbered sixteenths, linked time controls with independent offsets,
Freeze and explicit Repitch/Fade/Jump. Surge's sinc read is replaced with linear
or cubic interpolation to keep arbitrary host block sizes sample-identical;
Hi-Quality is not advertised as Live's proprietary tape model. Bandpass is an
ADI first-order HP/LP pair; Morph/wander/transition laws are provisional.
The UI-specific graph dragging and collapsed-LFO affordance belong to the
future device UI, not this top-level Pd audio patch.

The patch takes BPM from adi.transport; LibPdEngine fills it from io.transport.
No host changes are needed. Intentional delay is not intrinsic latency (reported
zero); Pd's separate adapter latency is included in timing expectations.

## Validation

MSVC Debug /WX: 91 DSP checks and 44 real-Pd checks pass. Exact impulse positions
at 1/10/125/1000/5000 ms, sync at 60/90/120/180 BPM, signed timing offset,
right-to-left Stereo Link, independent feedback, Ping Pong and Freeze tested.
The time-edit maximum step is Repitch 0.018861, Fade 0.019285, Jump 0.290382.
HQ interpolation differs from linear; the bandpass rejects out-of-band energy.
All seven LFO waves × six rate modes remain finite. Each transition mode is
sample-identical across blocks 32–4096. Processing allocates nothing.

Real Pd: clean console, zero C++/Windows Debug CRT process allocations, sine
peak 0.400000001 after far-bin floor check. The io.transport test sees an exact
quarter-note impulse at 32064 (90 BPM) and 24064 (120 BPM), including 64 samples
of adapter latency. Test renders float WAV to file only. No README count edit.
