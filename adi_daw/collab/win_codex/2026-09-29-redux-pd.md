# Redux — manual checklist before implementation

Mission 4, delegated by win. Branch: `codex/redux-pd`. This checklist is
written before the DSP or patch. Reference: Live 12 manual, chapter 28.30,
printed pages 615–616 (`reference/DOCS/DAWs/Ableton_live12/28d ...pdf`).
The text below paraphrases the chapter; no reference artwork is copied.

## Acceptance checklist

- [x] Rate reduces the sampling clock; with filters disabled, a sine above
  the reduced Nyquist frequency aliases to the predicted frequency.
- [x] Jitter varies that clock independently across stereo channels, producing
  noise and width; resetting a render repeats its result deterministically.
- [x] Pre limits bandwidth before the hold stage and reduces jitter-induced
  stereo differences; Post suppresses images after it.
- [x] Post-Filter Octave moves the post cutoff relative to half of Rate.
- [x] Bits reduces amplitude resolution; extreme reduction destroys dynamics.
- [x] Shape gives quieter amplitudes finer resolution than louder amplitudes.
- [x] DC Shift offsets the signal before quantization and changes distortion.
- [x] Dry/Wet interpolates between dry and processed audio; 100% supports sends.
- [x] The top-level stereo Pd patch declares every parameter with `adi.param`
  and connects `adc~` through the compiled-in external to `dac~`.
- [x] Measurements cover the processing claims, identical output for block
  sizes 32 through 4096, and zero allocations in processing.
- [x] LibPdEngine opens the real patch without console errors, produces a
  measured tone (far-bin floor checked first), and renders only to files.
- [ ] Human side-by-side acceptance (ADR-0108): pending win/director session.

## Source and parameter questions

ADR-0187 d2 explicitly has no Surge counterpart for Redux. Its d3 names
Bespoke BitcrushEffect or Airwindows DeRez and requires our own jitter.
Win clarified on 2026-09-29: implement our own plain sample-and-hold core;
DeRez and Bespoke are references, not the engine. The original implementation
is MIT-licensed. No source from either reference or Surge is incorporated.
Unlike DeRez's voiced hold interpolation/edge softening, this intentionally
retains the abrupt hold transitions and aliases. Live behavior is the target.

## Provisional control table — all values unverified against Live

Win approved proposing ADI values pending one director-led Live 12 session.
Every numeric range, default, unit and curve below is **unverified against
Live**. Names correspond to the manual; underscores only join Pd label words.
The pictured preset is not used as evidence for defaults. The follow-up must
replace this single table and the matching DSP/patch declarations together.

| Live control | ADI range | ADI default | Unit | ADI curve / interpretation |
|---|---|---|---|---|
| Rate | 20–48000 | 48000 | Hz | Log control; fractional sample-and-hold; capped at host sample rate |
| Jitter | 0–100 | 0 | % | Linear depth; independent uniform hold-period deviation up to ±95%, minimum one host sample |
| Bits | 1–24 | 16 | bits | Linear, continuous fractional resolution; step = 2^(1−Bits), mid-rise quantizer; exact silence retained without DC Shift |
| Shape | 0–100 | 0 | % | Linear control; signed power compander exponent 1/(1+3·Shape/100), inverse after quantizing |
| Pre | 0–1 | 0 (off) | toggle | Two cascaded one-pole lowpasses at Rate/2 before holding |
| Post | 0–1 | 0 (off) | toggle | Two cascaded one-pole lowpasses after quantizing |
| Post-Filter Octave | −4–4 | 0 | octaves | Linear octave control; cutoff = Rate/2 × 2^Octave, clamped below host Nyquist |
| DC Shift | 0–1 | 0 (off) | toggle | Add half a quantization step before quantizing; no output DC cancellation |
| Dry/Wet | 0–100 | 100 | % | Linear amplitude crossfade |

The filter order, compander, quantizer rounding and jitter distribution are
ADI choices, not claims of matching Live's undocumented transfer functions.
Hard input saturation at ±1 is also provisional. Human parity is still open.

## Validation

- MSVC Debug `/WX`, with `ADI_WITH_PD=ON`.
- DSP: 24 checks. 7 kHz at an 8 kHz clock folds to 1 kHz, amplitude
  0.39007658 for a 0.4 input. Fractional 7.5 kHz clock folds 6.5 kHz to 1 kHz,
  amplitude 0.37632041. Pre attenuates the first alias to 0.10292770.
- Quantizer resolution, quiet-signal Shape improvement, DC Shift, filter
  imaging attenuation, octave movement, Dry/Wet and jitter width are measured.
- All power-of-two block sizes 32–4096 are sample-identical with jitter,
  fractional Rate/Bits, Shape, and both filters enabled. Zero process allocations.
- Real LibPdEngine: 20 checks, clean console, zero C++/Windows Debug CRT
  allocations. Far bin 1.7e-11 is checked before the 0.390076584 alias peak.
  `redux-pd-render.wav` is a 32-bit float file in the test working directory;
  no audio hardware is opened.
- Fault plant: replacing the processed output with dry input fails 11 DSP
  checks and the real-patch alias assertion. Source restored before validation.
