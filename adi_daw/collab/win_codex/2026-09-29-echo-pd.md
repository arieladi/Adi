# Echo - checklist before code

Read Live 12 section 28.14, pp.573-577; SST Delay.h and FloatyDelay.h (Surge reference pin 58914e59c608ed4384ba6002e44c3465c58b2e71).

- Independent/linkable L/R time and sync, Notes/Triplet/Dotted/16th, independent offsets. Stereo/PingPong/MidSide routing.
- Input gain/distortion, feedback/invert, resonant HP/LP filter.
- Six LFO shapes, BPM sync, stereo Phase, delay amount/x4/filter amount, envelope blend.
- Input Gate and output Ducking with thresholds/releases; Noise amount/morph; Wobble amount/morph; Repitch or crossfade time edits.
- Reverb amount/decay at pre/post/feedback positions; wet Width/Output/DryWet/equal-loudness.
- Prove echo sample positions and tempo modes, ping-pong/MS, filtering, dynamics, deterministic noise/wobble, block identity, no allocations, real-Pd sound/floor/console and WAV-only output.

Adapt Surge Delay's stereo read/feedback/write topology and FloatyDelay's shared-sine plus correlated smooth-noise modulation. Scalar cubic delay interpolation; Live control mappings and dynamics are ADI additions. A small four-line diffusion network supplies the reverb control, not Live's proprietary reverb. Values remain provisional until director comparison.

## Validation and differences

MSVC /WX: 34 DSP checks and 64 real-Pd checks pass. Measured stereo, alternating ping-pong/inverted repeats and M/S reconstruction; all four synced note modes match exact impulse centroids. Link and offset, filter attenuation, gate rejection, ducking, deterministic noise, wobble, LFO sync and all reverb placements pass. Blocks 32..4096 are identical with noise/wobble/reverb enabled; process allocates nothing. A delay edit has largest step 0.047671463 with crossfade versus 0.308527965 with intentional repitch. Real Pd produces the expected -6 dB tone after a floor-bin check. io.transport gives quarter-note impulses at 32064/24064 samples for 90/120 BPM, including 64-sample adapter delay. All controls route and the console is clean; float WAV only.

Surge Delay supplies stereo feedback/read/write architecture; FloatyDelay supplies the shared sine plus correlated smooth-noise warp. ADI uses cubic interpolation, its own scalar resonant filters, envelope/gate/duck laws, and four-line reverb. Noise LFO has its own rate-controlled state; Wobble Morph blends periodic and irregular motion on both channels. Link copies time/sync/mode both ways while offsets stay independent. Dynamics use the linked stereo peak. Envelope modulation is bounded to [-1,1], and the 26-second rings cover the longest allowed synced time plus offset and both modulation depths. The device does not reproduce Live private circuitry, GUI, or the eight-second CPU auto-suspend optimization; noise remains active when enabled. LFO sync follows BPM rather than absolute transport phase. README counts untouched.
