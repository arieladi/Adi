# Reverb — manual checklist before implementation

Mission 4, delegated by win. Live 12 §28.32, printed pp.618–622, read first.

- [ ] Switchable low/high input cuts before the wet path.
- [ ] Early reflections with Spin Amount/Rate and Shape controlling their
  prominence/overlap with the late response.
- [ ] Late diffusion network, low/high frequency-dependent decay shelves,
  Diffusion and Scale, optional Chorus Amount/Rate.
- [ ] Predelay before first reflection; Size and None/Fast/Slow smoothing.
- [ ] Decay means measured -60 dB tail time; Freeze sustains, Flat bypasses
  decay shelves while frozen, Cut rejects new diffuse input while frozen.
- [ ] Stereo width to mono, Density quality/cost, Reflect/Diffuse level, Dry/Wet.
- [ ] Measured RT60 with stated tolerance, blocks 32–4096 identical, no process
  allocations, real-Pd far-bin-first sound/clean console, file-only renders.
- [ ] Director's side-by-side session and single unverified-values table.
