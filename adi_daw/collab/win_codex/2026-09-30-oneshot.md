# OneShot — checklist before implementation

Live 12 Simpler, printed pp.762–772; ADR-0169 P1 and ADR-0200 native sampler. Own wording:
- Classic: pitched polyphonic playback, ADSR, Start/Length/Loop, zero-crossing Snap and loop crossfade; oldest-voice stealing and same-note retrigger.
- 1-Shot: monophonic, no loop; Trigger ignores note-off, Gate releases, region fade-in/out.
- Slice: region/beat/transient/manual boundaries, chromatic slice keys, Mono/Poly/Thru, Trigger/Gate, per-slice fades.
- Filter: clean low/high/band/notch, 12/24 dB, cutoff and resonance. No claim to proprietary Cytomic circuit parity.
- Per-voice LFO sine/square/triangle/saws/random, Hz or tempo sync, pitch/volume/pan/filter destinations. Amp ADSR.
- Native parameter declarations feed the existing DAW panel; state carries immutable sample data and controls, reloadable through the existing device state path.
- File-only end-to-end Session render; floor bin before tone, pitch and mode measurements, all block sizes 32..4096 identical, zero allocations in process, publish sample while rendering, state round trip.

Choice: native DeviceInstance, not Pd. ADR-0200 names the native sampler; ADR-0169's later Sampler extends this voice engine. Fixed voice storage and direct note events preserve sample offsets and avoid a second MIDI/patch-block adapter. Source is original GPL-3 code.

Parity limits declared before coding: the existing clip engine explicitly refuses warp (clip_playback.cpp). This first sampler does conventional variable-speed pitch; it does not claim Live warp/stretch algorithms. The mission's Classic/1-Shot/Slice, region/loop/fade, filter, LFO and amp envelope are the delivery scope. Waveform editor, warp and proprietary analog circuits remain separate work. Every ADI-chosen range/default/curve is recorded together in the PR table; manual-verified numbers are distinguished.

Implemented original native OneShot (internal/adi.oneshot), resolved by Session before external loaders, including headless/offline sessions. File → Add OneShot from sample decodes off audio, stores content-addressed component state with embedded float audio, and submits track/chain/device/panel as ONE undo transaction. Sample data travels through publisher.hpp; the audio thread never owns or destroys its buffers. Current sample swaps stop old voices on the next block; no stale sample pointers survive reclamation.

Validation: native MSVC /WX; 100 OneShot checks including all 4065 integer block sizes 32..4096, FFT floor then fundamental/octave, ADSR sample times, mono/poly/voice stealing, Trigger/Gate, four slice methods, loop sustain, filter attenuation, LFO/block invariance, exact float-file and state round trips, concurrent publication, and zero audio allocations. Real Session resolves the production native device and renders its MIDI clip to float WAV. Document integration tests cover import/one-undo/redo; UI reference tests remain unchanged and pass.

Interpolation is linear, not a claim of Live's resampling/warp quality. Clean TPT state-variable filters are original ADI code; no Cytomic circuit copying. Transients are a deterministic off-audio amplitude-onset heuristic, not Live algorithm parity. Manual slice markers are supported by the publication/state API; the waveform editing GUI is outside this first voice-engine delivery. Basic per-voice LFO retriggers at note-on; extended LFO attack/offset/key tracking and envelope looping remain parity follow-ups. The import accepts up to 64 MiB of decoded mono/stereo float data and embeds it so project relocation does not break sample paths.

Frequency LFO .01..30 Hz, Transpose +/-48 st and Detune +/-50 cents are confirmed by the manual pp.770–771, but their defaults/curves remain ADI choices. Slice maximum 64 is manual p.767.
