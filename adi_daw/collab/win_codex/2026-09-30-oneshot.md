# OneShot — checklist before implementation

Live 12 Simpler, printed pp.762–772; ADR-0169 P1 and ADR-0200 native sampler. Own wording:
- Classic: pitched polyphonic playback, ADSR, Start/Length/Loop, zero-crossing Snap and loop crossfade; oldest-voice stealing and same-note retrigger.
- 1-Shot: monophonic, no loop; Trigger ignores note-off, Gate releases, region fade-in/out.
- Slice: region/beat/transient/manual boundaries, chromatic slice keys, Mono/Poly/Thru, Trigger/Gate, per-slice fades.
- Filter: clean low/high/band/notch, 12/24 dB, cutoff and resonance. No claim to proprietary Cytomic circuit parity.
- Per-voice LFO sine/square/triangle/saws/random, Hz or tempo sync, pitch/volume/pan/filter destinations. Amp ADSR.
- Native parameter declarations feed the existing DAW panel; state carries immutable sample data and controls, reloadable through the existing device state path.
- File-only end-to-end Session render; floor bin before tone, pitch and mode measurements, all block sizes 32..4096 identical, zero allocations in process, publish sample while rendering, state round trip.

Choice: native DeviceInstance, not Pd. ADR-0200 names the native sampler; ADR-0169's later Sampler extends this voice engine. Fixed voice storage and direct note events preserve sample offsets and avoid a second MIDI/patch-block adapter. Source is original GPL-3 code.

Parity limits declared before coding: the existing clip engine explicitly refuses warp (clip_playback.cpp). This first sampler does conventional variable-speed pitch; it does not claim Live warp/stretch algorithms. The mission's Classic/1-Shot/Slice, region/loop/fade, filter, LFO and amp envelope are the delivery scope. Waveform editor, warp and proprietary analog circuits remain separate work. Every ADI-chosen range/default/curve is recorded together in the PR table; manual-verified numbers are distinguished.
