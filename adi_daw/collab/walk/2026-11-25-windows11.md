Walker: walk-A, a helper of win, by the director's order of 25 November 2026.
The session walked is ADR-0248 decision 2 (adi_daw/docs/DECISIONS.md), owed by 3 December.
Sister report: walk-B on branch `walk/windows10`, same folder.

## The machine

- OS: Windows 11 IoT Enterprise LTSC 2024 (10.0.26100), 16 logical cores.
- Audio: one output only, an HDMI display's audio (NVIDIA HD Audio, WASAPI). **No audio input of any kind**
  (the onboard codec exposes no capture endpoint; no microphone, no line-in).
- No virtual audio cable or virtual MIDI port is installed, and the walk runs without administrator rights,
  so none can be installed (a driver install needs elevation). See "What this machine could not check".
- VST3 instruments installed: several third-party ones; the walk used an open-source synth.
- Build: origin/main at 73e26e4aa, RelWithDebInfo (optimised, with symbols), Ninja, MSVC 2022,
  `-DADI_WITH_JUCE=ON -DADI_WITH_PD=ON -DADI_WERROR=ON -DADI_ACCEPTANCE=ON`; targets `adi_app` and `adi_plugin_scanner`.
- ADI started with `ADI_HOME` set to a new empty folder; projects saved to a scratch folder outside the repo.
- Driven with: the session's computer-use tools (real mouse and keyboard input, screenshots after every action).

## Findings

| Id | What | Cause | Status |
|---|---|---|---|
| A1 | Two modal error boxes on every project open when the driver grants a buffer size other than the one chosen. WASAPI shared mode always grants its period (480 frames at 48 kHz), so every Windows user without ASIO sees them. The first box comes from the device's change callback writing the granted size into `audio.bufferSize`, whose choices are only 64…4096 in powers of two. The second is the mismatch report, shown as an alert | `src/juce/ui_main.cpp:1414` (settings write-back) and `:1125` (report as AlertWindow). The setting's own help, `src/adi/settings/registry.cpp:850`, says a driver that grants another size "still runs and is shown as granted" (ADR-0145 d5) | open |
| A2 | Ctrl+T (Insert Audio Track) with a track selected lands a track the Arrangement does not draw; the tracks after it keep their indices, so two tracks share index 4 | to find | open |
| A3 | New Project asks for a file before any project exists; Live opens an untitled set at once. ADI already makes `Untitled(n).adi` in the projects folder at launch with no dialog | `src/juce/ui_main.cpp:1366-1376` | open |

Notes from the walk that are not faults:
- The walker's own first misclick in the New dialog opened a network location and hung the Windows file dialog (a shell timeout, not ADI). ADI was closed and the step redone.
- Ctrl+S is Take Snapshot, not Save. This is a ruled deviation (ADR-0203 d6), so it is not a finding.
