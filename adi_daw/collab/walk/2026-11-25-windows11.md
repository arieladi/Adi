# Walk A — the one session, in the real window, on Windows 11 (25 November 2026)

Walker: walk-A, a helper of win, by the director's order of 25 November 2026.
The session walked is ADR-0248 decision 2 (adi_daw/docs/DECISIONS.md), owed by 3 December.
Sister report: walk-B on branch `walk/windows10`, same folder.

## The machine

- OS: Windows 11 IoT Enterprise LTSC 2024 (10.0.26100), 16 logical cores.
- Audio: one output only, an HDMI display's audio (NVIDIA HD Audio, WASAPI). **No audio input of any kind**
  (the onboard codec exposes no capture endpoint; no microphone, no line-in).
- No virtual audio cable or virtual MIDI port is installed, and the walk runs without administrator rights,
  so none can be installed (a driver install needs elevation). See "What this machine could not check".
- VST3 instruments installed: several third-party ones; the walk used an open-source synth.
- Build: origin/main at 73e26e4aa, RelWithDebInfo (optimised, with symbols), Ninja, MSVC 2022,
  `-DADI_WITH_JUCE=ON -DADI_WITH_PD=ON -DADI_WERROR=ON -DADI_ACCEPTANCE=ON`; targets `adi_app` and `adi_plugin_scanner`.
- ADI started with `ADI_HOME` set to a new empty folder; projects saved to a scratch folder outside the repo.
- Driven with: the session's computer-use tools (real mouse and keyboard input, screenshots after every action).
