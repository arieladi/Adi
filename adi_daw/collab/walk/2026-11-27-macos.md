Apple Silicon, macOS 26.6.2 and a native Debug build of `90f4091d241d1ae4b8690e74fafd1124d4611f0c`. The test instance used its own `ADI_HOME`. BlackHole 2ch carried the test signal and digital output capture. The control loop delivered a 440 Hz tone at −29.03 to −29.04 dBFS RMS on both channels. ## Findings

- **M1 / SC-392 — silent audio input.** macOS TCC refused the app's request for microphone-service authorization because its bundle lacked `NSMicrophoneUsageDescription`. The virtual input uses the same permission as a physical input. The app target is declared at `src/juce/ui_shell.cmake:127`. The known signal and refusal were reproduced with the native bundle.
- **M2 — system plug-in scan stops early.** An unreadable rollback directory under the system VST3 folder makes the scan incomplete, at `src/adi/scan_prune.cpp:93`. Selecting a readable folder containing the installed instrument allowed the scan and the live-note check to finish. The traversal is shared code.
