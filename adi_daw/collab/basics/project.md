## For the director

- Should an edited Untitled file reopened explicitly still prompt for a name on its next Ctrl+S? I recommend persisting its unnamed status if that recovery workflow should resume first-save behavior. The current branch distinguishes songs created in the active document from explicitly opened files.

- The safety queue has its own active log. The project session is keeping its safety drafts local and moving to the project wave-two rows after the first queue. Linux cannot verify the cross-drive Save As edge where a different relative file competes with the valid original-location hint. I recommend checking that case on Windows with SC-106.

- On the SC-86 and SC-09 landing stack, I recommend calling `capturePluginState()` in `ProjectDocument::startTrackRender` before reading the committed snapshot, applied sequence or undo head. SC-86 starts fresh render sessions from saved state for Freeze and both Bounce modes. Verify that a change made inside a plug-in without a change notification is heard in the render.
