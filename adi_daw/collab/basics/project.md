The current branch distinguishes songs created in the active document from explicitly opened files.

### SC-08 Settings audit

176 of 234 Settings rows are marked unavailable. 55 keys have literal references outside the registry and layout tables. The script compiles the real registry and tab layout, then searches production C/C++ sources for exact key literals. It skips comments and registry/layout definitions. References are evidence to inspect because a writer, an unused helper or a placeholder can mention a key. The reviewed list also follows indirect consumers, including MIDI port name, Track and MPE. `audio.graphWorkers` is internal and outside the count. Reproduce with `python tools/audit_setting_readers.py --evidence` from `adi_daw/` after fetching the JSON headers.

Test Tone, Tone Volume and Tone Frequency now drive the audio-device output. Test Tone is transient and turns off when Settings closes. The two existing decode-cache size limits now reach the cache. `cache.folder` needs safe cache replacement. The earlier SC-103, SC-104, SC-135 and SC-100 settings remain available. Open on start and its template path are dimmed. The main window currently needs a document and a start with no project needs a window that can open or create one. Template creation and loading are tracked by SC-161. Keep Monitoring Latency and Record Quantize populate new-track defaults. Recording needs to act on those defaults, as tracked by SC-255 and SC-60. SC-405 covers the custom MIDI Ports table outside the generic rows. Its Sync and Remote switches and all four output switches still lack their intended behavior.
