## For the director

- **SC-316, a MIDI-effect plug-in changing what the synth plays.** It needs the graph to carry the notes a device makes on to the next device, which it cannot do today for any device, ADI's own included. I recommend one engine ADR (an event output on a node, a fourth `EventFlow`, `Transform`, whose output replaces its input for what follows), built once for the built-in MIDI effects (DEV-18) and then used by both plug-in hosts; until then the Browser should not offer a hosted MIDI effect in front of an instrument as if it worked.
- **Delete inside a plug-in's window deletes ADI's selection: answered 27 November, keep it as Live.** A key the plug-in does not take acts on ADI's selection, Delete included (Undo brings it back). Nothing to change.
- **A plug-in window reopened at its kept place can run off the screen** (seen with Surge XT after a held-off open: kept left edge, full size). Small; not fixed here.
- **SC-324 turns round an earlier contract.** The loader's tests said a VST3 saved at another path must stay a placeholder, "without identity guessing". Live finds a plug-in by its ID wherever it is installed, so ADI now does: same format, name and class ID. A different class ID is still never guessed. If two copies of one plug-in are installed in two folders, the first in the catalogue's order is taken.
- **SC-319: Rescan lifts only the scanner's own blocks.** A block placed by hand stays (an older contract of the scanner says so). No window lists the blocked plug-ins yet; Live has no such list either, so I left it out.
- **SC-329, a plug-in's own presets: your choice of scope.** I recommend, the Live way as I know it: in the plug-in device's menu its own program list where it declares one (a VST3's programs; a CLAP's presets when it offers preset discovery), choosing one is one undo step; and "Load Preset File..." for a `.vstpreset`. Saving goes to ADI's own preset file (SC-85's form), not to `.vstpreset`, so one kind of file holds the device and its plug-in state. Reply "SC-329: as recommended", or say what differs.
- **For win:** the `adi_play` break of `land/basics-1127e` is fixed on that stack (`357647ae`); the chain has it.
