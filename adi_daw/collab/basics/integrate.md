## For the director

- SC-398. Should EX-04 receive the libFLAC and LAME dependency grants? I recommend the planned pinned in-process encoders, including LAME 3.100. The published Export chain includes AIFF.
- SC-100. Should explicitly reopening an edited Untitled file restore its first-save naming prompt? I recommend persisting the unnamed state for this recovery workflow. The integrated behavior currently treats an explicitly opened file as named.
- SC-157. The current Safety prompt explicitly asks for scheduled backups, while ADR-0255 d6 describes snapshots and no timer. I used the current prompt and retained snapshot-triggered copies. I recommend updating the older decision to match.
- SC-277. Reserve format rows for track input taps and Sends Only under MX-25 and XC-15. I recommend foreign-key input rows and separate track output state so copy, import and Undo can remap their identities. The SC-261 candidate covers direct Audio To. Internal MIDI input and capture also need the DEV-20 ownership contract.
- SC-250. Recovery uses the complete on-disk audio prefix from a recorder manifest. Existing WAV-only leftovers and in-memory MIDI need separate recovery. I recommend Windows network-path and power-cut qualification before extending the supported recovery claims.
- SC-406. May the route format persist hardware zones and add per-device channel ranges under a revision of ADR-0097? I recommend per-track MIDI To settings for hardware, an additive per-device field with CLAP and VST3 capability checks, and an explicit rule for overlapping zones on the same hardware port. Keep the current lower-zone default for older projects.
