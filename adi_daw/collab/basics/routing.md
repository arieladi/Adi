## For the director

For the SC-261 Linux gate, I recommend running the unchanged window suites on native Linux. The guest measured a 779.89 ms browser search against the 40 ms SC-421 bound and a 752.30 ms owner turn against the SC-415 relative bound. Isolated reruns with the same executables again failed both bounds. The browser median was 184.69 ms for the common prefix, and the slow-open fixture measured a 1,254.23 ms owner turn. Both fixtures and their feature paths match main. The upstream source equivalent to this item's base passed these suites in the [main Linux UI job](https://github.com/arieladi/Adi/actions/runs/46020442251/job/140578472188). The measurements above are from the item head in this session's guest.

Win reserved schema 1.28 for SC-404's native per-track MIDI output in #823. The staged table holds the endpoint identifier, saved name and MIDI channel 1–16. Activation follows the lower minors as recorded in the reservation. Review the text projection and migration wiring with activation.

Reserve a schema minor for SC-277's native track-to-track input and output states. I recommend the MX-25 format with foreign keys on both tracks, a source tap for Audio From, post-effects MIDI From, and a track-owned choice for Sends Only and No Output. The audio input and output mode DDL is staged. Existing `routing` rows handle explicit audio destinations. I recommend adding an event-only graph edge with per-source note and pedal release on rewiring before exposing nonexclusive MIDI From. The current Main edge carries audio as well as MIDI, and a removed edge can strand notes on its old receiver.

Approve the SC-406 optional hardware zone columns as part of the staged SC-404 migration before activating schema 1.28. I recommend project-owned plug-in zone storage keyed by device instance, so two instances of the same plug-in can keep different configurations after reopening. The draft uses existing MIDI To and device MPE menus. [Ableton plug-in MPE guide](https://github.com/Ableton/ableton.github.io/blob/main/plugins/mpe-support-plugins.md#example-cc-event-sequences-to-indicate-mpe-mode-and-zone-configuration)

For SC-269 I recommend an impulse test with nonzero plug-in latency before ruling on linear placement, punch limits and loop pass alignment. The draft captures Main and excludes the recording track. [Ableton Live manual](https://www.ableton.com/en/live-manual/12/routing-and-i-o/#resampling)
