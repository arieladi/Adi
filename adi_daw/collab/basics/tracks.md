## For the director

- R12 is still open. I recommend leaving the copied track disarmed until it is explicitly armed. The branch sets that policy in `kCopyArmState`. Copies of frozen tracks use their editable source because a rendered freeze cache belongs to the original identities.

- R13 is still open. I recommend double-click and Delete reset to 0 dB for the fader and silence for a send. The gestures are provisional constants in the mixer.

- For SC-85 under ADR-0258 d18, I propose one versioned, readable ADI JSON preset per file in the User Library. Store the plug-in format, UID and shell identity, the display name and normalized parameters, plus optional named base64 plug-in state streams. Track placement and automation stay in the song.

- R50 is still open. I recommend keeping the existing refusal when a known instrument is double-clicked with an audio track selected until the Live reading confirms automatic MIDI-track creation. The branch builds the known-instrument path with no selection and records the audio-track choice in `kNewMidiTrackWhenAudioSelected`.
