## For the director

- **SC-196 / N53.** Where does Live place its crossfade when only one side has hidden source material, or when neither does? I recommend keeping the visible seam and limiting a linked crossfade to valid source on both sides. A Windows Debug PCM regression reproduced the dip with full source handles. It also checked that Undo restores the join and that two separately authored fades still dip. The full-handle fix needs a reserved format minor for explicit linked overlap bounds that can be removed without moving either clip. Can Win reserve that minor? I recommend storing the overlap separately from existing fade domains, which also preserve fades across splits.
- **SC-198.** Does Live audition audio outside a clip's placed Start and End when the Sample Editor scrub strip is clicked there? I recommend limiting the existing Arrangement playback action to the placed clip until that routing is measured.
- **SC-210 / SC-211.** TM-WT-02 assigns Win the format minor for per-clip Warp settings and the origin used by Set 1.1.1 Here. I recommend a separate clip origin field so pickups remain addressable and the existing AWRP marker stream stays readable. Can Win reserve the minor and choose the origin representation?
- **SC-213.** ADR-0258 requires changed external sample content to play with a notice. If another app has already overwritten the bytes before ADI sees the change, what should Undo restore? I recommend accepting changes at recorded paths that ADI has verified, preserving old bytes before an ADI-launched edit when possible, showing historical clips as offline when those bytes are unavailable, and keeping existing frozen renders immutable. A media refresh must also recapture the sample slots whose stored state contains decoded PCM.
- **SC-216.** The audio Clip View can store a local Scale, and no current ADI device consumes Clip or Set ScaleContext. I recommend DEV-22 Auto Shift as the first opt-in consumer and the Set scale when playing clips supply no unambiguous local scale. Which device should consume it first, and what should happen when two playing clips have different scales?
- **SC-219.** TM-SV-02 plans a persistent RAM setting for launched clips, and the current audio clip format has no RAM flag. I recommend one clip-owned flag that Arrangement and future Session playback can share, with bounded preparation on a worker. Can Win reserve its format location?
- **SC-217.** AU-06 and ADR-0230 require a format minor for relative clip modulation. Existing overlays store absolute values and do not carry linked Warp or independent envelope clocks. I recommend reserving that minor and starting with pre-FX Gain, then adding additive pitch to the Warp render recipe and signed Sample Offset to the Beats reader. Can Win assign the format minor and confirm those clocks?
- **SC-33.** The reverse edit refuses a selection that combines the intro before the loop with a later wrap. Warped loops still choose their starting phase in beats across song tempo changes. How does Live handle each case? I recommend an undoable split for the intro and the rendered sample clock for the repeated portion. I also recommend checking a trimmed clip that extends beyond its source before deciding how to position the silent tail when reversed. [Live Clip View manual](https://www.ableton.com/en/live-manual/12/clip-view/)
