# The Master Reference v1.0 review, as evidence

These three files are win's ledgers from the director's review of Master Reference v0.9.9
(1 to 12 October 2026). They are the evidence behind ADR-0203 and are committed so that
whoever builds next can read the director's words, not only win's summary. The document
itself lives outside the repository (`reference/` is git-ignored).

| File | What it is | Read it for |
|---|---|---|
| `v1.0-verdicts.md` | **The ledger.** Every verdict and directive, in the director's words where he gave them, with the date. The last table rows are the latest rulings (the three final questions; licensing). | The ruling on any audit id (A1-10, B4-22, D-04 …). **When this file and anything else disagree, this file wins.** |
| `v1.0-catchups-final.md` | The 146 catch-up lines, one per document item, in document order, each naming the ruling that shaped it; the three questions (since answered, see the ledger); the 13 moot items. | What the v1.0 document says about each item. **Its licence lines (A1-03, A5-15 to A5-18, B2-24, B3-17, B5-22, A9-01) are superseded by the AGPL ruling of 12 October**: ADI is AGPLv3 in full. |
| `v1.0-ableton-rule.md` | The standing rule applied to the remaining decisions: §1 the lines it settles, §2 the earlier rulings it would change if applied backwards (shown, not changed), §3 the questions it raised, §4 the measurements. | How a line was reasoned. **§1 and §3 were written before the director's answers of 5 October**; where they differ from the ledger (sends-choice-2, -3 and -4, A3-14, A4-12, A4-19, A1-07, A7-30, B5-25, A6-17, A6-20, A7-05, B2-11, B5-20, A6-22), the ledger wins. §4's measurements are now `docs/AWAITING.md` rows 6 to 15. |

The audit itself (374 findings, 584 KB) is not committed; its ids are explained by the ledger's
entries, and its proposals for the document were applied in the document.
